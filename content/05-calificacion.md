# 05 · Calificación de leads

## Campos (`guardar_lead`)
| Campo | Notas |
|---|---|
| nombre | Completo si es posible |
| whatsapp | Se toma del remitente |
| correo | Opcional pero pedirlo |
| segmento | S1, S2, S3, S4 |
| unidad | vclg_saas, vclg_insumos, vclg_belleza, vclg_elearning, gzm |
| necesidad | Texto libre breve |
| tamaño_etapa | Nº profesionales / etapa de empresa |
| urgencia | inmediata, 1-3 meses, explorando |
| consentimiento | Aceptó que lo contacten |
| notas | Contexto relevante |

## Puntaje
- **HOT:** necesidad clara + urgencia inmediata o pide reunión/precio + entrega datos de contacto → notificar a Marco/equipo al instante.
- **WARM:** interés claro, sin urgencia o sin datos completos → seguimiento en 48 h con plantilla.
- **COLD:** curiosidad o comunidad → sin seguimiento comercial.

## Reglas
- Pedir datos solo cuando hay interés; un dato por mensaje.
- Pedir consentimiento antes de guardar datos personales.
- Nunca solicitar datos clínicos de pacientes.
